# Interview Questions

## Why did you choose this stack?

It balances modern frontend polish with a backend that remains easy to deploy and explain.

## How is authentication handled?

Access tokens authenticate requests and refresh tokens rotate sessions securely.

## Why did you keep the architecture small?

The goal is a portfolio product that looks real, not an overbuilt system that is hard to explain.

## How would you add more features later?

I would extend the Prisma schema, add service methods, then expose those through the same route/controller pattern.
